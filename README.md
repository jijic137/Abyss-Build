# 深渊构筑 / Abyss Build

> 仿《土豆兄弟》(Brotato) 的 **HTML5 + Canvas 2D Roguelike**。纯前端、零依赖、零外部资源——美术是运行时字符网格拼装的像素风，音效与 BGM 是 WebAudio 程序化合成，**直接双击 index.html 即可游玩**。

---

## 特性

- **20 波 = 20 关**：普通波逐渐加长加密，精英按轮换表登场，双 BOSS（第 10 波腐化巨兽、第 20 波深渊之主）。
- **构筑系统**：8 个职业、22 项角色属性、5 档稀有度（白到红）；123 物品（普遍「正面 + 少量负面」）、37 把武器，考验取舍。
- **商店与升级**：每波结束 4 卡位（购买/锁定/重掷/出售）；升级卡约 1/4 为「权衡卡」（同时带红字负面属性）。
- **强化反馈**：购买/升级有粒子爆发 + 脉冲辉光动画 + 音效；命中、击杀、受击、BOSS 均有对应音画反馈。
- **精英 / BOSS 分离**：精英走轮换表（w5/w9/w14/w15/w17/w19 六次覆盖全部 6 种），BOSS 波不出精英，节奏更清晰。
- **经济自平衡**：怪物数量翻倍后，用全局 MAT_MUL（概率化掉落）反向校准，使每波材料总量仍约等于旧配置。
- **本地存档**：最高波次 / 击杀 / 历史最佳 / 成就 / 统计存 localStorage；设置（音量、震屏、BGM、音乐）记忆。

## 快速开始

```bash
# 方式一：起一个本地静态服务器（推荐，避免个别浏览器 file:// 限制）
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：直接双击 index.html 用浏览器打开
```

> 需要现代浏览器（Chrome / Edge / Firefox）。无需联网、无需安装任何依赖。

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | W A S D / 方向键 |
| 射击 / 自动攻击 | 武器自动开火（部分需瞄准） |
| 暂停 / 设置 | ESC |
| 开始 / 继续 | 标题与暂停页按钮 |

对局内 ESC 可暂停并进入设置，开关 BGM、调节音乐音量、屏幕震动与音效音量。

## 开发脚本（在仓库根目录运行）

```bash
# 无头回归：驱动双档案跑满 20 波，日志见 _smoke3.log，错误数=0 即通过
node tools/_smoke_waves.js

# 经济校准：输出建议的 G.MAT_MUL（改完 05_enemies.js 的 W 后跑一下看每波偏差）
node tools/_calib_econ.js

# 重新生成内容登记表
node tools/_gen_registry.js
```
