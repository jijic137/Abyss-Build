# 深渊猎手 / Abyss Hunter

> 仿《土豆兄弟》(Brotato) 战斗内核的 **HTML5 + Canvas 2D 搜打撤 Roguelike**。纯前端、零依赖、零外部资源——美术是运行时字符网格拼装的像素风，音效与 BGM 是 WebAudio 程序化合成，**直接双击 index.html 即可游玩**。

---

## 玩法循环：搜刮 · 战斗 · 撤离

```
整备仓库 → 选择深渊区域 → 进图探索 → 达成目标 → 撤离点开放 → 活着回来 → 战利品入仓
                ↑                                        │
                └──────── 死亡 = 本局一切全丢 ←───────────┘
```

- **整备仓库**：武器×2 / 防具×1 / 饰品×2 / 遗物×1 六格装备栏，仓库存放带出物（可扩容），市场用深渊币买卖，扩容/门票/刷新构成经济出口。
- **深渊区域（5 档）**：裂隙边缘 → 幽暗回廊 → 深部矿坑 → 深渊腹地 → 终焉之门。房间网格随机连通 + 迷雾逐房揭示 + 小地图 + 区域主题地表，探索中藏有宝库 / 精英房 / BOSS 房 / 圣泉 / 祭坛 / 事件房 / 传送门，还有需要深渊钥匙开启的锁门。
- **撤离**：达成目标后撤离点开放（T1 存活 60s、T2 杀精英、T3 击败腐化巨兽、T4 双精英、T5 击败深渊之主），站入引导撤离；材料 1:1 折现，首通奖励并解锁下一层。
- **风险与收益**：死亡失去本局携带的一切（装备 + 背包 + 材料），撤离才能把战利品带回仓库——犹豫、贪心、撤退，是同一个决策。

## 特性

- **构筑系统**：8 个职业、22 项角色属性、5 档稀有度（白到红）；123 件物品（自动分为防具/饰品/遗物，普遍「正面 + 少量负面」）、42 把武器（5 档品质），考验取舍。
- **属性碎片（替代等级）**：打怪/事件掉落碎片，攒满 3 颗触发一次强化选择，属性写进角色基底并随存档保留。
- **每局随机性**：开局随机 1~2 个深渊词缀（怪潮/精英成群/宝箱丰收/材料横流/迅捷猎手/坚实护甲/祝福/诅咒/黑暗/疾风），每局地图布局、房间类型、上锁房门、事件与传送门均不同。
- **探索乐趣**：房间网格地图、门洞与墙体（视线遮挡）、迷雾与小地图、6 种特殊房间 + 单向传送门、上锁房门与深渊钥匙、随时可走的撤离点。
- **开箱反馈**：稀有容器呼吸辉光 → E 键引导进度环 → 开盖动画帧 + 闷响粒子震屏 → 出货卡片弹出（白→红逐级加码的音效/射线/辉光/飞行动画）；世界坐标互动标签不再遮挡 HUD。
- **连续挑战**：撤离点可选「继续深入下一层」，保留装备/战利品/材料/钥匙并叠加深层奖励，一局直达终焉之门；死亡仍全丢。
- **机关与陷阱**：爆炸桶可被子弹引爆、范围伤害敌我并可连锁；尖刺陷阱周期预警弹出；战斗房宝箱精简定点，宝库房成为出货核心。
- **美术**：容器（木箱/铁箱/金箱/深渊箱）实体像素、环境装饰（白骨/岩石/水晶/火把/藤蔓/碎石）、5 区域主题地板与墙体，全部程序化生成，零外部资源。
- **战斗系统**：9 种敌人 AI + 精英词缀变异（狂暴/分裂/吸血/护盾）+ 两阶段 BOSS 技能，命中/击杀/暴击全链路粒子与音效反馈。
- **经济自平衡**：怪物数量翻倍后用全局 MAT_MUL 概率化掉落反向校准；局外「深渊币」与局内「材料」双层货币。
- **本地存档**：局外元存档（货币/仓库/装备栏/档位解锁/词缀与钥匙状态）与局内战局快照（进图即存，可继续游戏）分别持久化于 localStorage，旧档自动迁移。

## 快速开始

```bash
# 方式一：起一个本地静态服务器（推荐，避免个别浏览器 file:// 限制）
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：直接双击 index.html 用浏览器打开
```

> 需要现代浏览器（Chrome / Edge / Firefox）。无需联网、无需安装任何依赖。

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | W A S D / 方向键 |
| 互动 / 开箱 / 开锁 / 事件 / 传送门 / 撤离 | E |
| 背包 | I |
| 属性面板 | TAB |
| 暂停 / 设置 | ESC |
| 射击 | 武器自动开火 |

对局内 ESC 可暂停并进入设置：BGM、音乐音量、音效音量、震屏强度均可调。

## 开发脚本（在仓库根目录运行）

```bash
# 无头回归：地图/撤离/死亡/读档/锁门/事件/碎片/词缀传送/T4 构筑（9 档案，错误数=0 即通过）
node tools/_smoke_waves.js

# 真实浏览器自检（需 Edge + 运行时 playwright）：真实存档读档、撤离、UI 遮挡、精灵尺寸
$env:NODE_PATH='C:\Users\ts\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules\.pnpm\node_modules'
node tools/_browser_check.js

# 重新生成内容登记表
node tools/_gen_registry.js

# 批量 AI 美术（调远程 ComfyUI 服务，断点续跑/自动重试；产物入 assets/art/ai/）
node tools/_gen_ai_art.js
```
