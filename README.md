# 深渊猎手 / Abyss Hunter

> 仿《土豆兄弟》(Brotato) 战斗内核的 **HTML5 + Canvas 2D 搜打撤 Roguelike**。纯前端、零依赖、零外部资源——美术是运行时字符网格拼装的像素风，音效与 BGM 是 WebAudio 程序化合成，**直接双击 index.html 即可游玩**。

---

## 玩法循环：搜刮 · 战斗 · 撤离

```
整备仓库 → 选择深渊区域 → 进图探索 → 达成目标 → 撤离点开放 → 活着回来 → 战利品入仓
                ↑                                        │
                └──────── 死亡 = 本局一切全丢 ←───────────┘
```

- **整备仓库**：武器×2 / 防具×1 / 饰品×2 / 遗物×1 六格装备栏，仓库存放带出物（可扩容），市场用深渊币自由买卖（白/绿开局直接购入，蓝/紫/红需集「贸易代币」升级市场解锁），扩容/门票/刷新构成经济出口。
- **深渊区域（5 档）**：裂隙边缘 → 幽暗回廊 → 深部矿坑 → 深渊腹地 → 终焉之门。房间网格随机连通 + 迷雾逐房揭示 + 小地图 + 区域主题地表，探索中藏有宝库 / 精英房 / BOSS 房 / 圣泉 / 祭坛 / 事件房 / 传送门，还有需要深渊钥匙开启的锁门。
- **撤离**：达成目标后撤离点开放并逐房揭示，站入引导撤离；材料 1:1 折现，撤离成功才能把战利品带回仓库并解锁下一区。**16 小关战役**贯穿 5 区：每小关独立目标（存活 N 秒 / 击杀精英 N / 击败区域 BOSS），深入下层保留装备与战利品、伤害 +8、回血 30%，区域 BOSS 关「深部矿坑·终」「终焉之门·终」。
- **风险与收益**：死亡失去本局携带的一切（装备 + 背包 + 材料），撤离才能把战利品带回仓库——犹豫、贪心、撤退，是同一个决策。

## 特性

- **构筑系统**：8 个职业、22 项角色属性、5 档稀有度（白到红）；123 件可装备物品（自动分为防具/饰品/遗物，普遍「正面 + 少量负面」）+ 31 件可收集宝物 + 42 把武器（5 档品质），考验取舍。
- **可收集宝物**：工艺藏品 / 能源燃料 / 电子物品 / 名画古董 / 潮流时尚等一大类「不参战」的宝贝，占格 1x1 ~ 3x3（画作、星象巨钟、织金壁毯等多件 3x3 贵重物最占空间也最值钱），宝库房、精英与 BOSS 会掉落；**宝物图鉴**共 31 件记录已搜刮的美术收藏与稀有度，记录页点亮收集进程；背包内点击即卖出换材料，带回仓库后可一键变现。**收集闭环**：图鉴进度提高宝物卖出价（每 20% +5%，集齐再 +25%），收集过半 / 集齐各发放一次深渊币赏金，给搜刮与取舍新的决策维度。
- **属性碎片（替代等级）**：打怪/事件掉落碎片，攒满 3 颗触发一次强化选择，属性写进角色基底并随存档保留。
- **职业亲合升级**：碎片强化的候选词条按角色定位加权——铁卫偏防御、游侠偏远程/攻速、术士偏元素/暴击等，构筑更贴合所选英雄。
- **每局随机性**：开局随机 1~2 个深渊词缀（怪潮/精英成群/宝箱丰收/材料横流/迅捷猎手/坚实护甲/祝福/诅咒/黑暗/疾风），每局地图布局、房间类型、上锁房门、事件与传送门均不同。
- **探索乐趣**：房间网格地图、门洞与墙体（视线遮挡）、迷雾与小地图、6 种特殊房间 + 单向传送门、上锁房门与深渊钥匙、随时可走的撤离点。
- **开箱反馈**：稀有容器呼吸辉光 → E 键引导进度环 → 开盖动画帧 + 闷响粒子震屏 → 出货卡片弹出（白→红逐级加码的音效/射线/辉光/飞行动画）；世界坐标互动标签不再遮挡 HUD。
- **连续挑战**：撤离点可选「继续深入下一层」，保留装备/战利品/材料/钥匙并叠加深层奖励，一局直达终焉之门；死亡仍全丢。
- **机关与陷阱**：爆炸桶可被子弹引爆、范围伤害敌我并可连锁；尖刺陷阱周期预警弹出；陷阱改为定点阵型（单战斗房 V 形伏兵线 / 合并大房门廊走廊 / 陷阱房环形守卫网），战斗房宝箱精简定点，宝库房成为出货核心。
- **整备与背包**：六格装备栏（武器×2 / 防具 / 饰品×2 / 遗物）局内实时穿脱，双饰品槽独立可选；背包与装备排行拖拽整理，悬停在已装备物品上显示完整详情；角色确认后先进整备仓库再选图出发。
- **背包与掉落**：局内背包物品可「丢」在地上腾出空间；开箱时背包若满，物品不再消失而是掉落在箱前，腾空后拾回即可——杜绝满包丢战利品。
- **驻守宝箱**：部分战斗/陷阱房宝箱外围生成驻守怪物（清除后才好安心开箱），出现率随层深入提升，越深的宝箱越多且越稀有（金箱/深渊箱占比显著抬升）。
- **美术**：容器（木箱/铁箱/金箱/深渊箱）实体像素、环境装饰（白骨/岩石/水晶/火把/藤蔓/碎石）、5 区域主题地板与墙体，全部程序化生成，零外部资源。
- **战斗系统**：9 种敌人 AI + 精英词缀变异（狂暴/分裂/吸血/护盾）+ 两阶段 BOSS 技能，命中/击杀/暴击全链路粒子与音效反馈。
- **英雄技能**：8 个职业各有一个主动技能（空格释放）：铁卫地裂 / 游侠箭雨 / 术士元素星爆 / 狂徒狂暴 / 工匠爆能过载 / 影刺客影袭 / 炼金术士毒雾 / 守望者守护圆舞，带冷却与 HUD 就绪/充能显示。
- **战斗 HUD**：底部整合为指挥条——左侧技能盘（冷却圆环 + 就绪辉光）、中间状态/目标、右侧武器栏；武器槽带序号、稀有度角标与冷却遮罩，桌面与移动端均不重叠。
- **开局即有怪**：进入下一层（深入）后出生房立即刷出一批敌人，不再出现“开局零怪慢慢才刷新”的空白期。
- **数值平衡**：小怪基础血量上调、白/绿武器基础伤害下调，早期不再是“一枪秒杀”，逼出走位与构筑取舍。
- **经济自平衡**：怪物数量翻倍后用全局 MAT_MUL 概率化掉落反向校准；局外「深渊币」与局内「材料」双层货币。
- **AI 美术集成**：选图卡 5 区域概念图、BOSS/精英立绘、基地/市场/记录/结算背景、事件插画——ComfyUI 批量产物随 assets/art/ai 落地，缺失时优雅降级（全部用于装饰，不影响游戏逻辑）。
- **随机台词**：怪物按情境说话（进房挑衅/受击/死亡/低血嘲讽/词缀/精英/BOSS 阶段），玩家 T 键快捷回应角色口头禅，世界坐标气泡限流。
- **本地存档**：统一持久化层（PlayerProfile 模型 + 存储后端抽象，预留账号体系）+ **三槽位自动存档**（切换/覆盖/快照）+ 导出/导入完整档案 JSON；局外元存档与局内战局快照分别持久化，旧档自动迁移。

## 快速开始

```bash
# 方式一：起一个本地静态服务器（推荐，避免个别浏览器 file:// 限制）
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：直接双击 index.html 用浏览器打开
```

> 需要现代浏览器（Chrome / Edge / Firefox）。无需联网、无需安装任何依赖。

对局内 ESC 可暂停并进入设置：BGM、音乐音量、音效音量、震屏强度均可调。

## 数值规划

- **武器品质曲线**：基础伤害乘子 白 0.82 / 绿 1.28 / 蓝 1.90 / 紫 2.85 / 红 4.10，冷却略降；同武器白→绿 DPS 约 +59%，绿→蓝约 +72%，越高级提升越明显，品质差异可感。
- **怪物成长**：`waveScale` 使小怪血量随波次大幅上浮（w4 +50%、w10 +93%），普通怪不再是「一枪秒」，前期一梭子才能放倒，逼出走位与构筑取舍；精英/ BOSS 有独立修正。
- **属性碎片**：角色不升级，靠击杀/事件攒碎片，集满触发一次强化选择；候选词条按职业亲合加权，构建立体且贴近角色定位。
