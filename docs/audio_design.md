# 深渊猎手 · 音效 2.0 设计文档

> 原则：**零外部音频文件、纯 WebAudio 程序化合成**。所有音效由振荡器 / 噪声 / 滤波器实时合成，不依赖任何联网资源，双击 index.html 也能出声。

## 一、设计理念

### 1. 分层混音（Layering）
每个"爽"音效都由三层构成，缺一不可：

| 层 | 作用 | 例子 |
|---|---|---|
| 瞬态层（Attack） | 前 5~20ms 的冲击，让耳朵"咯噔"一下 | 高频噪声点击、方波起音 |
| 主体层（Body） | 音色主体，决定性格 | 方波/锯齿波下坠、带通噪声 |
| 尾巴层（Tail） | 混响/余韵，给"重量"和空间感 | 卷积混响 send、低频 sine 拖尾 |

### 2. 频段分工
- **低频**（< 200Hz）：重量、恐惧、力量——底鼓、Boss 咆哮、击杀 thump；
- **中频**（200~2kHz）：打击感、机械感——命中、挥砍、开箱；
- **高频**（> 2kHz）：闪耀、清脆、奖励感——暴击碎裂、出货闪光、金币。

一个典型设计（红品出货）：
低频底鼓（重量）→ 中频和弦（情绪）→ 高频琶音 + 钟声（闪耀）→ 长混响（殿堂感）。

### 3. 随机化消除机械感
保留 12_audio 的随机 detune；多版本音效内部也做微音高/微时序差异，连射时不会像复读机。

### 4. 节流与性能
每个音效有独立最小间隔（`GAPS2`），同帧大量命中不会叠成噪音墙；全部合成廉价（短时长、少量节点），并给主总线加了 DynamicsCompressor，堆叠时瞬态更稳、不削波。

## 二、三档音效风格（多版本方案）

全局风格（设置页「音效风格」可切换，持久化在 `localStorage.abyss_hunter_sfx_style`）：

| 档位 | 名称 | 参数特征 | 适合 |
|---|---|---|---|
| 1 | 经典 | 增益 0.92、混响 0.8、单层点缀 | 保守、清晰的经典合成器味 |
| 2 | 冲击（默认） | 全参数 1.0、双层点缀 | 标准爽感：瞬态足、有重量 |
| 3 | 史诗 | 增益 1.06、混响 1.4、三层点缀 | 大场面：更华丽、更宽广 |

接口：
```js
G.Audio.setSfxStyle(1|2|3)      // 全局切换
G.Audio.setSfxVariant('crit', 3) // 单音效覆盖
G.Audio.clearSfxVariant('crit')  // 恢复跟随全局
```

## 三、出货分级（白 → 红）

稀有度 0=白 / 1=绿 / 2=蓝 / 3=紫 / 4=红，音效逐级叠加层数：

### 开箱 `chest_open_t0..t4`（按容器品质自动选档）
| 容器 | 档位 | 构成 |
|---|---|---|
| 木箱 / 桶 | t0 | 开盖闷响 + 单音 ding |
| 木箱（好货） | t1 | + 第二音上挑 |
| 铁箱 | t2 | + 三和弦 + 琶音 |
| 金箱 | t3 | + 底鼓 + 四和弦 + 高闪噪声 |
| 深渊箱 | t4 | + 五和弦 + 六连琶音 + 双钟声 + 长混响（出货高潮） |

### 物品弹出 `loot_t0..t4`（G.Loot.sfx(tier) 自动路由）
白：单 blip；绿：双音；蓝：和弦+琶音；紫：和弦+闪耀+扫频；红：底鼓+五和弦+六连琶音+钟声。

### 拾取 `pickup` / `item_get`
材料/金币用清脆双音（硬币感）；装备入包用闪耀琶音（v1/v2/v3）。

## 四、流程音效

| 音效 | 触发 | 设计 |
|---|---|---|
| map_enter | 进图 | 低频下坠 + 风声 + 次低音（深渊感） |
| descend | 深入下一小关 | 下滑扫频 + 落地 thump + 上行琶音（推进感） |
| extract_ready | 撤离点开放 | 明亮和弦（希望感） |
| extract_start | 引导开始 | 双段上升脉冲（充能感） |
| extract_done | 撤离成功 | 胜利级大和弦（释放感） |
| save | 手动存档 | 温和双音 + 小 thump（确认感） |
| levelup | 属性碎片/升级 | 上行四和弦 + 琶音 |
| buy / reroll | 市场 | 硬币双音 / 洗牌噪声 |
| abyss | 标题进入 | 漩涡低鸣 + 扫频 |

## 五、扩展性

- 新音效：在 `EXTRA2` 加一个函数，命名按 `名字` / `名字_v2` / `名字_v3` / `名字_t0..t4` 约定，自动获得变体/分级解析；节流只需在 `GAPS2` 补一行。
- 新风格档：在 `STYLE` 加一档参数即可。
- 接外部音频：未来若想用真实采样，只需把 `EXTRA2` 某函数替换为 `AudioBufferSourceNode` 播放（或保留程序化版做备用回退），调用方无需改动。
- 音色主题化：`STYLE` 或按地图主题（T1~T5）给 send / bright / thump 做环境差异，可在 `G.Audio` 上加 `setEnv(theme)` 按层调整混响量和音色，已预留 `styleParams()` 读取点。

## 六、验证

- `tools/_check_audio.js`：Node 内用 fake AudioContext 跑通全部音效（含所有变体与分级）合成路径，零异常；
- `tools/_smoke_waves.js`：全脚本加载零错误；
- `tools/_browser_check.js`：浏览器内打开试听页点击代表性音效无 console 报错。
